MULTI-ANGLE 4K PROMPTS - copy and paste
=======================================
None of these prompts describe the character (no gender, height, build, face or hair). Your uploaded AI character image supplies all of that.
OUTFIT: every prompt has one sentence that starts 'In every view the character wears ...'. Delete that sentence to keep the character's own outfit, or change it to any outfit you like.

HOW TO USE (about a minute to learn)
 1. Open a NEW Gemini chat and choose the best image model on your Pro plan (ask for 4K).
 2. Attach your AI character image (the best, clearest one; add a second angle if you have it).
 3. Paste STEP 0 below together with the image and send. Wait for the reply.
 4. For each scene paste ONE "SHEET PROMPT". Gemini returns ONE image showing the same character from 4 camera angles, like a 3D turntable.
    Download the original full-size PNG (not a screenshot).
 5. Rename the file exactly as shown (for example hello_sheet.png) and send it to me in this chat, or put it in the inbox folder.
    I cut each view out, line them up, upscale to 4K if the sheet is smaller, and wire them into the site.
 6. Keep all sheets in the SAME chat so the character and the camera distance stay consistent.

If a sheet disappoints, use the ONE-BY-ONE prompts under the same scene: one image per angle (more pixels per pose).
Any number of poses works, from one up. Scenes you skip keep their current look.

FILE NAMES
  hello_sheet.png  (optional second sheet: hello_sheetB.png)
  anchor_sheet.png
  office_sheet.png
  desk_sheet.png   (optional second sheet: desk_sheetB.png)
  home_sheet.png
  storm_01.png storm_02.png storm_03.png      (backgrounds, no character)
  cockpit_01.png cockpit_02.png cockpit_03.png (optional, the gaming section)
  One-by-one versions are named hello_01.png, hello_02.png ... as shown.

ANGLE WORDS USED
  front = facing the camera straight on.   three-quarter left/right = turned about 35 degrees toward the viewer's left/right.
  profile = turned 90 degrees (a side view).   over-the-shoulder = turned away, looking back at the camera.   low / high = camera below / above eye level.
